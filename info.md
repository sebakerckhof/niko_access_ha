# Niko Access Control (2-wire)

Unofficial Home Assistant integration for the **Niko Access Control 2-wire**
video door station (a Hikvision 2-wire OEM), via the Niko/Hik-Connect cloud.

**Works:** doorbell `ring` events, call state, door unlock, and **local live
video** (pulled directly from the station over your LAN — Home Assistant must be
on the same network). Set up with your Niko app account; the door-station IP is
auto-detected (SADP).
